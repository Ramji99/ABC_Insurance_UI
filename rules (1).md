# Skill: Layout & Composition Rules (`layout.skill.md`)

## Description
Defines container placements, grid safe zones, brand hierarchy, and legal disclaimer structures.

## Layout Grid & Structure

### Header Elements
* **Brand Logo:** Placed top-right, minimum width `114px`. Maintain clear space equal to 1 icon element width.
* **Partner/Product Logo (If Applicable):** Placed top-left, height must not exceed the main ABC ERGO logo height.

### Content Hierarchy (Top-to-Bottom)
1. Headline (Short, intriguing copy)
2. Sub-head (Concise product benefit/clarification)
3. Body Copy and Mnemonics
4. Brand Communication Box (BCB)

### Footer Elements
* **Product Band:** Solid band filled with Health Blue (`#009FE3`). Includes product name and category icon.
* **Legal Disclaimer:**
  * **Font Family:** `Times New Roman, serif`
  * **Font Size:** `7pt`
  * **Minimum Surface Area:** 10% of total display area
  * **"Conditions Apply" Clause:** Minimum 50% font size of main content
