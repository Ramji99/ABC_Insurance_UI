# Skill: Brand Theme Configurator (`theme.skill.md`)

## Description
Applies ABC ERGO Health design tokens, color bands, and typography rules across all UI components.

## Specifications

### 1. Typography Hierarchy
* **Font Family:** `Inter, sans-serif`
* **Scale Settings:**
  * **Headline (100%):** `50pt` / Line-height: `1.1`
  * **Sub-headline (70%):** `35pt` / Line-height: `1.2`
  * **Body Copy (50%):** `25pt` / Line-height: `1.4`

### 2. Brand Components
* **Brand Communication Box (BCB):**
  * **Background Color:** Red (`#E31F26`)
  * **Text Color:** White (`#FFFFFF`)
  * **Placement Rules:** Can hang from top or rest at bottom of layout.
* **Product Color Band:**
  * **Category:** Health Insurance
  * **Band Color:** Light Blue (`#009FE3`)
